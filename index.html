1. feladat Macskák

Ez a táblázat egy pár lehetséges lekérést mutat be.

Url Leírás
/cat Will return a random cat
/cat/tag Will return a random cat with a tag
/cat/gif Will return a random gif cat \o/
/cat/says/text Will return a random cat saying text
/cat/tag/says/text Will return a random cat with a tag and saying text
/cat/says/text?fontSize=size&fontColor=color Will return a random cat saying text with text's fontSize and text's fontColor
/cat?filter=filter Will return a random cat with image filtered by filter (blur, mono, negate or custom)
/cat?filter=custom&brightness=brightness&lightness=lightness&saturation=saturation&hue=hue Will return a random cat with image filtered by brightness, lightness, saturation and hue
/cat?filter=custom&r=red&g=green&b=blue Will return a random cat with image filtered by red, green and blue

Ebben a feladatban kipróbálhatsz egy api-t. A fenti szabályok szerint add meg a kép forrását, majd nyomd meg a gombot.

Hogyan működik?

Ahhoz, hogy a fenti feladatban a vlasztott kép megjelenjen az oldalon, az alábbi kód fut a háttérben.
